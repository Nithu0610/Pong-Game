# 🚀 Quick Start - Démarrage Rapide

Lancez votre jeu Pong en 30 secondes!

---

## ⚡ Super Rapide (30 secondes)

### Juste Jouer
1. Double-clic sur **`index.html`**
2. Cliquez **"Start Game"** ou appuyez **SPACE**
3. Utilisez **W/S** pour contrôler votre raquette
4. Amusez-vous! 🎮

---

## ⏱️ Un Peu Plus Détaillé (2 min)

### Lancer Avec Un Serveur Local

**Windows**:
```bash
double-clic sur run.bat
```

**Mac/Linux**:
```bash
bash run.sh
```

**Accédez**: `http://localhost:8000`
